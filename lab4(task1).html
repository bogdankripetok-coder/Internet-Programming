Теоретичні відомості


1. Об'єктна модель документа (DOM)

DOM (Document Object Model) — це програмний інтерфейс (API) для HTML та XML документів. Він представляє структуру документа у вигляді дерева об'єктів, де кожен HTML-тег є окремим вузлом.


2. Пошук елементів

  • document.getElementById(id) — пошук за унікальним ідентифікатором.
  • document.querySelector(cssSelector) — повертає перший елемент, що відповідає CSS-селектору.
  • document.querySelectorAll(cssSelector) — повертає колекцію всіх елементів за селектором.

3. Обробка подій та форм

Для призначення реакції на дії користувача використовується метод addEventListener('event', callback). При роботі з формами метод e.preventDefault() зупиняє стандартне відправлення сторінки.
